# SSRS_Projects — аналітичні звіти `Polyclinic_Reports`

Етап 5: звіти SQL Server Reporting Services над OLAP-кубом `Polyclinic DW`.

| Файл | Призначення |
|---|---|
| `Polyclinic_Reports/Polyclinic_Reports.slnx` | Рішення Visual Studio (Report Server Project у підпапці) |
| `Polyclinic_Reports/Polyclinic_Reports/PolyclinicOLAP.rds` | Спільне джерело даних (Shared Data Source): `OLEDB-MD`, база `Polyclinic_OLAP`, Windows-автентифікація |
| `Polyclinic_Reports/Polyclinic_Reports/DS_*.rsd` | 7 спільних наборів даних (Shared Datasets) для списків параметрів |
| `Polyclinic_Reports/Polyclinic_Reports/*.rdl` | 7 звітів (5 обов'язкових варіанту + реєстр пацієнтів + підзвіт) |
| `VERIFY_REPORTS.sql` | Тестування параметрів і даних звітів через linked server `SSAS_POLYCLINIC` (27 перевірок PASS/FAIL) |

## Розгортання

1. Visual Studio → `Polyclinic_Reports.slnx` → **Build** → **Deploy** (цільовий сервер `http://<сервер>/ReportServer`, налаштований у властивостях проєкту).
2. На сервері створюються папки: `Поліклініка/Звіти`, `Поліклініка/Datasets`, `Поліклініка/Data Sources`.
3. Портал: `http://<сервер>/Reports` → `Поліклініка/Звіти`.
4. Налаштування порталу — розділ нижче (обліковий запис `ssrs_reader`, роль куба, безпека, кеш, підписка).

## Тестування

### `VERIFY_REPORTS.sql` — 27/27 PASS

Виконується в SSMS з Windows-автентифікацією після `../SSAS_Projects/VERIFY_CUBE.sql` (він створює linked server `SSAS_POLYCLINIC`). Запити MDX — ті самі, що в наборах даних звітів, з підставленими значеннями параметрів.

| Група | Що перевіряється | Приклади результатів |
|---|---|---|
| **A. Списки параметрів** (11) | кількість значень спільних наборів = сховище; значення за замовчуванням є у списках; немає порожніх Value / Label; каскад Відділення → Спеціальності → Лікарі; пошук пацієнта без урахування регістру; порожній пошук (AllowBlank) | 11 років, 16 відділень, 30 лікарів кардіології, 5 вікових груп, 17 розділів МКХ-10; «mc-0000012» → рівно 1 пацієнт |
| **B. Дані звітів** (13) | підсумки кожного звіту при тестових параметрах = `PolyclinicDW`; Boolean-параметри змінюють результат коректно | кардіологія 01–06.2025: 3 371 візит, 449 867,91 грн; KPI 2025 = 64,73 % (жовта зона, статус 0); діагнозів 2025: 87 753, без архіву Філії №2 — 82 984; реєстр за 12.2025 — 7 316 пацієнтів |
| **C. Безпека параметрів** (3) | `STRTOMEMBER` / `STRTOSET` з `CONSTRAINED` відхиляють неіснуючий член і довільний MDX-вираз (захист від MDX-ін'єкції); межі діапазону дат 2016–2026 існують у вимірі Дата | помилка «restrictions imposed by the CONSTRAINED flag» |
| **D. Продуктивність** | час запитів звітів через linked server | усі запити 30–70 мс |
