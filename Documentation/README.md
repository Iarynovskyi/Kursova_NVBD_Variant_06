## Структура записки (за методичкою)

1. Вступ (2–3 с.)
2. Розділ 1. Аналіз предметної області (8–10 с.)
3. Розділ 2. Проєктування бази даних (10–12 с.)
4. Розділ 3. Реалізація ETL-процесів (8–10 с.)
5. Розділ 4. Побудова OLAP-куба та аналітичні звіти (8–10 с.)
6. Висновки (2–3 с.)
7. Список використаних джерел
8. Додатки: SQL-скрипти, скріншоти інтерфейсів, звіти

Обов'язково в записці: ER-діаграми (концептуальна, логічна, фізична), схема сховища (зірка), схеми ETL (Data Flow), архітектура куба (виміри й міри), скріншоти звітів з описом, SQL-скрипти; аналіз продуктивності (OLTP vs OLAP, вплив індексів і агрегацій, оптимізація, масштабування); тестування (обмеження цілісності, ETL, обчислення куба, параметри звітів).
