# Архів прийомів Філії №2 (джерело для SSIS)

Філія №2 до 2026 року вела облік прийомів у застарілій системі. Вивантаження з неї складається з 10 річних CSV-файлів за 2016–2025 роки, загалом **40 044 рядки**. Ці дані ETL-процес має очистити, стандартизувати й об'єднати з основною OLTP-базою (Union All) у сховищі `PolyclinicDW` з ознакою `SourceSystem = 'BRANCH2'`.

Файли згенеровано скриптом `../GENERATE_BRANCH_ARCHIVE.py` (детерміновано, seed 20260001). Усі записи посилаються на реальні медичні картки пацієнтів і ліцензії лікарів з `PolyclinicOLTP`.

## Формат

| Параметр | Значення |
|---|---|
| Кодування | UTF-8 з BOM (code page 65001) |
| Роздільник | `;` |
| Text qualifier | `"` |
| Перший рядок | заголовки колонок |
| Природний ключ | `RecordNo` = `B2-<рік>-<номер>` → у DW `DiagnosisID_Source = рік × 1 000 000 + номер` |

Колонки: `RecordNo; VisitDateTime; PatientCard; DoctorLicense; ICD10; VisitType; Severity; DurationMin; CostAmount; Currency; IsFreeNSZU; Outcome; RecoveryDate; SickLeaveDays; Complaints`

## Навмисні дефекти та очікувана обробка в ETL

| Дефект | Приклади | Частка | Трансформація SSIS |
|---|---|---|---|
| Повні дублікати рядків | однаковий `RecordNo` | 609 рядків (1,5%) | **Sort** (Remove duplicates) |
| Різні формати дат | `dd.MM.yyyy HH:mm`, `yyyy-MM-dd HH:mm:ss`, `dd/MM/yyyy HH:mm` | 40% нестандартних | **Derived Column** → `yyyy-MM-dd` (**Data Conversion**) |
| Некоректні дати | `31.02.2019 10:00`, `н/д`, `00.00.0000` | 107 | **Conditional Split** → `etl.ErrorRecords` |
| Номер картки в різному написанні | `mc-0001234`, `␣␣MC-0001234␣`, `MC0001234` | ~15% | **Derived Column** (TRIM, UPPER, вставка дефіса) |
| Неіснуюча картка пацієнта | `MC-0090000+` | 116 | **Lookup** no match → `etl.ErrorRecords` |
| Ліцензія лікаря з пробілами/малими літерами | `lic-ua-100037` | ~12% | **Derived Column** |
| Неіснуюча ліцензія | `LIC-UA-9xxxxx` | 137 | **Lookup** no match → `etl.ErrorRecords` |
| Код МКХ-10 у різному написанні | `␣j06.9␣`, `I21,9` | ~20% | **Derived Column** (TRIM, UPPER, `,`→`.`) |
| Невідомий код МКХ-10 | `X99.9`, `J06.99` | 74 | **Lookup** no match → `etl.ErrorRecords` |
| Тип візиту, тяжкість, результат у різному регістрі; порожні | `первинний`, `ПОВТОРНИЙ`, `` | 25–30% | **Derived Column** (нормалізація), NULL → значення за замовчуванням |
| Тривалість з одиницями виміру | `25 хв` | ~3% | **Derived Column** (видалення « хв») |
| Порожня тривалість | `` | 814 | NULL → норматив спеціальності (**Lookup** DimDoctor) |
| Тривалість поза діапазоном 5–180 | `0`, `-15`, `999`, `1440` | 161 | **Conditional Split** → `etl.ErrorRecords` |
| Десятковий роздільник | `346,67` / `346.67` | 40% з комою | **Derived Column** + **Data Conversion** (DT_NUMERIC) |
| Валюта | `UAH`, `грн`, `EUR`, `€` | 3 281 у EUR | **Lookup** `dbo.RefExchangeRate` → конвертація в грн |
| Булеве значення | `1/0`, `так/ні`, `true/false` | — | **Derived Column** → DT_BOOL |
| Порожня кількість днів лікарняного | `` | — | NULL → 0 |

Після очищення лишається близько 38 800 коректних унікальних візитів. Приблизно 600 рядків відсікаються як помилкові: вони потрапляють у `etl.ErrorRecords` з кодом і причиною помилки.
